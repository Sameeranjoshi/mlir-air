# GEMV Tutorial 4: Parameters {#tut-gemv-04-params}

We\'ve written a complete program that copies data to and from the
device, but both our host and device still need to define the dimensions
`M` and `N`. Now we introduce compile time parameters to set `M` and `N`
while compiling our code, and show how our host code can read these
values from the compile output.
